# 测试与验证

本项目提供 Swift Testing 单元与集成测试、应用包冒烟检查、离屏界面预览和手动联网检查。当前版本的执行结果见 [版本验证](../APP_VERIFICATION.md)。

## 离线测试

运行 `bash scripts/test.sh`；可用 `--filter MonitorStoreTests` 筛选。测试不访问第三方网络，使用人工最小响应、模拟服务和独立 UserDefaults 域。

如果在受限执行环境中出现 `sandbox-exec: sandbox_apply: Operation not permitted`，可在该环境允许时运行 `bash scripts/test.sh --disable-sandbox`，仅关闭本次 SwiftPM 的嵌套沙箱，不修改系统工具链、应用权限或 CI 配置。2026-10-09 本地完整回归使用此参数，56 项测试全部通过。

| 范围 | 覆盖行为 | 测试位置 |
| --- | --- | --- |
| 配置 | 首次空配置、间隔范围、来源一致性、兼容配置读取、去重、极值步进 | Tests/Configuration |
| 行情与目录解析 | 主连筛选、昨收/昨结口径、字段缺失、零成交量、目录分页和代码 | Tests/Quotes |
| 行情状态 | 首次失败占位、失败保留成功值、恢复清错、拒绝旧行情 | Tests/Quotes |
| K线链接 | 内置品种无行情时的链接、连续代码校验、拒绝月份代码 | Tests/Quotes |
| 公司资料 | 单位、比例、手续费、部分失败缓存、参考金额计算 | Tests/Broker |
| 任务与节流 | 配置切换、暂停、旧响应隔离、查询间隔、资料查询触发 | Tests/Monitor、Tests/Quotes |
| 展示模型 | 行距计算、置顶保存、数字分组与精度、占位符 | Tests/Monitor、Tests/Quotes |

## 应用包与界面检查

- `--self-test`：验证包内目录资源、模拟查询、配置恢复和暂停，不修改真实用户配置。
- `bash scripts/render-previews.sh`：渲染演示行情与设置页，输出到 `doc/images/`。离屏渲染不能代替真实交互检查。
- `--live-check`：手动访问真实目录、行情和公司资料接口，不纳入普通离线 CI。

## 手动验收范围

| 范围 | 预期 |
| --- | --- |
| 配置页 | 搜索、全选、取消、排序、切换来源、保存与取消正确；无效输入不能保存 |
| 行情表格 | 多品种与全部指标下，固定首列和表头，横向列名对齐，长名称与错误状态可辨认 |
| 列宽与窗口 | 拖动、恢复默认、缩放、重启后的列宽与窗口位置恢复正确 |
| 生命周期 | 暂停、睡眠、唤醒、置顶和窗口重开符合[架构说明](architecture.md) |
| 无障碍与外观 | 键盘、VoiceOver、深色模式和提高对比度下可操作、可读 |
| 网络与平台 | 慢网络、限流、长时间监控及目标架构下行为正确 |

人工最小响应不能证明上游完整页面、接口长期稳定性或全部品种数据正确。数据授权、Developer ID 签名和公证需独立确认。
