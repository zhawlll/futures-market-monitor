# 架构与边界

原生SwiftUI/AppKit行情小窗，按选定来源监控主连。假设公开接口能返回所需字段，允许部分品种失败；不承诺所有接口或品种持续可用。

| 模块 | 职责 |
| --- | --- |
| Application/ | 应用入口、菜单、状态栏、窗口、睡眠/唤醒生命周期 |
| Configuration/ | 配置草稿、数据源、品种与指标选择、安全间隔步进 |
| Quotes/ | 品种、指标、快照与按行状态；HTTPS、请求节流和行情解析 |
| Monitor/ | 属性级 Observation Store、独立轮询、行情表与资料详情 |
| Broker/ | 单位/保证金/手续费解析、缓存与参考金额 |
| Sources/FuturesMonitor/Testing/ | 应用包冒烟检查、模拟服务；独立联网检查 |
| Tests/ | 按功能组织的独立 Swift Testing 单元与集成回归 |

UI草稿仅在保存时提交；真实配置保存在当前用户UserDefaults域。行情与公司资料只存在本次运行内存。没有服务器、数据库、登录会话、用户角色或认证声明；无需服务器RLS。数据提供方收到客户端直接HTTPS请求，是主要外部边界。远端返回值视为不可信输入，解析失败由对应行或资料列处理。

每个顶层类型独立存放。配置窗口仅跟踪实际读取的 Store 属性，行情行更新不会发布整个对象的变更。置顶由行情窗口直接修改，保存配置草稿时保留当前置顶值；窗口显示时同步面板层级。数字显示使用 FormatStyle，保留原有分组、小数位与正负号约定。

Package.swift 的 FuturesMonitorCore 目标只编译业务模型、解析器、服务和 MonitorStore，排除 UI、应用入口及冒烟工具。应用继续由 scripts/build.sh 构建。MonitorStore 的 save、togglePause、stopWorkers 返回被取消的任务句柄，调用方可忽略；测试等待这些任务完成，验证取消后晚返回的结果不会污染当前状态。测试模拟服务不使用真实网络，各测试使用独立 UserDefaults 域并清理。

MonitorTableView 用一个共享纵向滚动容器放置首列及行情区域，仅行情区域嵌套横向滚动。LazyVStack 的 Section 表头固定在顶部，HorizontalScrollObserver 观察行情区域原生NSClipView的位移并同步到指标表头；表头使用独立裁剪区域和不透明背景。两侧使用相同行高和间距，首列不会随横向滚动移动。InstrumentCellView 使用原生 Link 交给默认浏览器；FuturesChartLink 验证东方财富主连代码，并显式映射新浪查询节点到连续代码。全部内置品种无行情时也可生成链接；未来未知新浪节点必须获得有效连续代码后才能链接，不推测月份合约。

品种列遵循[Apple表格设计建议](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables#macOS)，通过表头分隔线调整列宽。InstrumentColumnResizeHandle处理拖动和无障碍增减，ResizeCursorView提供系统调整光标；MonitorStore独立保存列宽。窗口变窄时只限制实际展示宽度，不覆盖已保存的偏好。名称中间省略保留首尾，完整名称由悬停提示提供。

## 已知限制

- FuturesQuoteService.swift 使用公开网页协议和token，接口变更及许可边界未解决。
- QueryGate 限制全局启动间隔0.5秒；大量品种可能排队，5秒是单次完成后的最低等待，不是所有品种同步刷新承诺。
- MonitorRow.succeed 保留较新行情，状态“正常”表示查询成功；没有交易日历或独立行情延时状态。
- BrokerReferenceParser 基于HTML形状解析；上游改版可能失败。一手保证金采用主连价格和公司公示比例，特殊合约不自动替代账户结算标准。
- 当前没有App Sandbox、Developer ID签名或公证；源码构建只作本地签名。
- 主界面实际点击与不同机器/Intel运行尚未验证，详见 tests.md。

## 数据与生命周期流程

### 保存配置

用户打开设置 → 创建内存草稿 → 选择来源、品种和指标 → 输入5–86400秒间隔 → 保存校验 → 取消旧任务并变更generation → 写UserDefaults → 启动新任务。

配置必须有来源、非空品种和指标，所有品种来源匹配；无效配置禁用保存且 MonitorStore.save 拒绝。取消草稿不保存。修改指标/间隔可保留相同来源相同品种的行情；切换来源后不混用旧缓存。副作用为本机配置写入及开始访问提供方，没有账户授权或支付。

### 行情与资料查询

每个品种任务 → QueryGate分配请求槽 → HTTPS提供方 → 检查状态码、字段、代码与时间 → MainActor更新该行 → 等待配置间隔。HTTP失败或无效响应不覆盖成功值，首次失败显示占位。不同品种独立。旧generation或已取消任务不得更新新配置。

选中资料指标时 → 一个共享资料任务 → 独立下载单位/保证金/手续费 → 各部分合并成功值 → 失败部分保留本次缓存并警告。初始行情失败时资料指标仍占位；无有效乘数或比例不估算金额。提供方只返回数据，不执行下载的JavaScript。

### 查看K线

点击品种名称 → 根据该品种数据源及连续代码构造固定官网地址 → 系统默认浏览器打开主连页面。不提交账户资料，不改变查询来源或轮询；网页会按网站自身行为请求数据。东方财富页面默认日K，新浪页面可切换日K。

### 停止、唤醒与退出

暂停或睡眠 → 取消任务、清理workers并变更generation；唤醒且未手动暂停 → 恢复任务。关闭窗口仍保留应用和轮询，用户通过菜单可再打开；退出应用终止任务，没有后台常驻辅助进程。

没有服务器权限检查。操作人是当前macOS登录用户；本机配置属于该用户，远端访问是公开网页协议，不代表获得数据商业许可。

## 权限矩阵

| 资源/操作 | 操作人 | 控制与失败行为 |
| --- | --- | --- |
| 监控配置读取/保存 | 当前macOS用户 | UserDefaults本用户域；提交前校验，草稿取消不写入 |
| 公开行情及目录GET | 运行应用 | HTTPS；无用户登录；节流；请求失败按行/目录处理 |
| 公司资料GET | 运行应用 | 仅选择资料指标后发起；共享缓存；部分失败独立处理 |
| 显示/关闭/置顶窗口 | 当前macOS用户 | AppKit本机窗口API；无需辅助功能权限 |
| 手动联网自检 | 启动命令的用户 | --live-check明确发起第三方网络请求 |
| 构建产物写入 | 执行构建脚本的用户 | 指定输出目录、本地签名，无root操作 |
| CI构建与自检 | GitHub runner | contents: read，不注入Secrets，不上传或自动发布 |

应用没有多用户服务、角色声明、数据库、RLS、交易操作、麦克风/摄像头/定位/辅助功能请求。当前应用未启用App Sandbox；操作系统当前用户权限是本地运行边界。不要将公开协议token当作账号身份或服务授权。

## 应用运行期间的轮询

| 任务 | 触发/间隔 | 函数 | 限制/重试 |
| --- | --- | --- | --- |
| 品种行情 | 保存配置或启动，每次查询后等待>=5秒 | MonitorStore.startWorkers | 独立Task；全局请求启动>=0.5秒；同品种启动>=5秒；下一轮重试 |
| 公司资料 | 选择资料指标时，成功30分钟/失败60秒 | BrokerReferenceService.fetch | 共享in-flight查询；至少60秒复用结果；按部分保留缓存 |
| 目录刷新 | 应用启动、切换来源或手动刷新 | loadCatalog | 同来源加载中不重复；失败保留内置目录 |

以上仅在应用进程存在期间执行，不创建系统cron、launchd或远端定时任务。没有用户账号Secrets或内部服务认证。任务取消与generation检查阻止旧请求写新配置；重复查询可更新同一行，不发起交易。查询时间与错误可在行情时间悬停详情查看，应用没有持久化运行日志。关闭窗口仍查询，暂停/退出停止，睡眠暂停并在唤醒时按手动暂停状态恢复。
